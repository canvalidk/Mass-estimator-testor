## Statement

$\eta=\min(1,\mathcal H/J)$ with $\mathcal H=-\sum_i\ell_i''$, $J=\sum_i\ell_i'^2$ at the series' best line $\hat\phi$ on the **whole projective line** of slopes (negative and infinite $m$ included), $\ell_i=g_iH_i/2$; $\eta=1$ when $J=0$. Forced: $\mathcal H/J$ by property N in the long-series limit (the width must track how far the point moves under repeats); one $\eta$ per series because $m$ is one number; **the raw $J$** (no $N/(N-1)$) by Z, since an exact zero reading has $\ell_i'=\ell_i''=0$ and a Bessel factor counts it (ours25's sandwich moved on appended zeros); the whole line because on $m>0$ the best line can sit at a boundary where the curvature measures nothing (ours25 then fell back to the prior); evaluation at $\hat\phi$ because the ratio is parametrisation-free only where the score vanishes (the swap follows); candidates unchanged by L19 (shrinking each cloud by $\eta$ would infer signal size from the series). Natural, not forced: the cap at 1; the power form at finite $N$ (O14). Removes the $\sqrt N$ growth of the null tilt and leaves a bounded floor (O15). Tested 1D–3D: quoted width 93.7–97% wherever there is signal at $N=200$; the point stops wandering on pure noise.

## Checked under R-2026-09-07-1 (29 Oct, Claude, provisional)

The misfit's whole-line Q measured the smallest error under a weaker law than the one assumed
(O13, 29 Oct). Is η's whole-line evaluation the same slip? **No, provisionally:**

- *Here the whole line is forced, by premises this theorem names.* On $m>0$ the best line can sit
  at a boundary, where the score does not vanish; there $\mathcal H/J$ depends on the
  parametrisation, and centring the scores to repair that is the Bessel-type factor Z excludes
  (an exact zero reading has $\ell_i'=0$ and would move the mean). Q had no such reason: $Q_+$
  is Z-exact, swap- and unit-covariant, and defined everywhere.
- *η is not an error needed under the law.* It compares the readings' disagreement about the
  slope with what the declared noise predicts, at the one point where that comparison is
  parametrisation-free.
- *Checked on data from the declared model* (`../../tools/eta_sign_check.py`, seed 2914; k = 2,
  true m = c = s = 1, 250 series per cell, `positivity=True`). Series whose best line lands at
  negative mass do cover worse, but as much without η, and η raises them:

  | cell | with η: φ̂ < 0 / ≥ 0 / all | η = 1: φ̂ < 0 / ≥ 0 / all |
  | --- | --- | --- |
  | null, N = 20 | 0.719 / 0.860 / 0.796 | 0.579 / 0.794 / 0.696 |
  | size 0.5, N = 20 | 0.703 / 0.911 / 0.880 | 0.622 / 0.831 / 0.800 |
  | size 1, N = 5 | 0.667 / 0.931 / 0.912 | 0.667 / 0.927 / 0.908 |

  So the gap is the law's weak-signal shape (the data pointed the wrong way, and the law on
  $m>0$ leans to a boundary), which is O14/O15's ground, not η's evaluation point. Conditioning on
  the sign of φ̂ is not ancillary, so the split alone would not have shown a defect either way;
  the η = 1 column is what separates them. One geometry only.
