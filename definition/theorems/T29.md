## Statement

any readout that averages a push size over each reading's candidate cloud changes when a null reading is appended: the cloud has non-zero size, and that size depends on $m$ through the noise units. ours28, 3D, +50 null readings: 2.2524 → 2.2406; law unchanged to $10^{-14}$. Using the size of each reading's **best-guess (conditional-mean) candidate** passes Z exactly, passes swap and the exact limit, and leaves the all-zero experiment with no readout.
