## Statement

any readout that averages a push size over each reading's candidate cloud changes when a null reading is appended: the cloud has non-zero size, and that size depends on $m$ through the noise units. ours28, 3D, +50 null readings: 2.2524 → 2.2406; law unchanged to $10^{-14}$. Using the size of each reading's **best-guess (conditional-mean) candidate** passes Z exactly, passes swap and the exact limit, and leaves the all-zero experiment with no readout.

## Proof or support

Carried from the records named in the status line. The exact Gaussian
different-instrument-ratio null-padding derivation is in `../../problems/O2.md`,
"An exact Gaussian point-Z counterexample" (28 Oct). Increasing size multipliers
prove point movement without changing the mass law. This supplies a counterexample;
it does not assert that every null append changes every series.

The best-guess repair's exact-zero neutrality does not establish composition.
O2 now has a finite-law counterexample, 2 ≠ 10/3, checked by
`tests/test_readout_composition.py::test_exact_finite_law_composition_values`.
It concerns the full composition-theorem domain, not a claimed Gaussian-adapter
output. No repair is adopted.
