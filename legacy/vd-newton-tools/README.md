# vd-newton-tools/: the thinking from VD-Newton's local `.tools/` folder

VD-Newton kept a gitignored `.tools/` folder of working scripts, notes and study
runs from the Codex sessions of 15 to 28 September. It was never on GitHub. On
2026-10-24, on his ruling that all thinking passes to the tester and only data
or old artefacts stay behind, every script and note in it that was not already
in the tester came here: 184 files (166 distinct contents) from 28 folders,
with the folder paths of `.tools/` kept as they were.

- **161 moved**: removed from `.tools/` after their hash was checked here.
- **20 copied**: scripts saved inside a study run's `source/` folder in
  `mass_estimator_studies/` or `mass_estimator_runs/`. They record which code
  made that run's data, and the data stayed in `.tools/`, so the original stays
  beside it. The copy here is the same bytes at the same path.
- **3 copied from test scratch**: script versions that existed only inside
  pytest temporary folders, which were then deleted.

`SHA256SUMS` lists every file. Scripts and notes in `.tools/` that were
byte-identical to files already in the tester (3,336 of them, mostly copies of the
VD-Newton lab's scripts that tests and studies dropped into run folders) were not
carried again.

## What stayed in VD-Newton's `.tools/`

The study outputs (about 1.3 GB of `.npz`, JSON, figures and logs, mainly
`mass_estimator_studies/` and `mass_estimator_runs/`), because it has not been
shown that they can be reproduced: only about a third of the scripts behind them
fix a seed. If they are tested and come back byte for byte, they can go. The
non-estimator folders (haze probe, NML3 probes, pass and receipt helpers, a
matplotlib install) also stayed, untouched. The twelve pytest scratch folders
(about 8,600 files, regenerated by any test run, cited by no record) were deleted.

## Local only

`estimator_assessment_2026_09_19/paper.txt`, `robot_pmd_20260916/paper_text.txt`
and `robot_pmd_20260916/thesis_chapter3_text.txt` are text extracted from
published work. They are gitignored for the reason `docs/papers/` is: this repo
is public. `SHA256SUMS` still lists them.
