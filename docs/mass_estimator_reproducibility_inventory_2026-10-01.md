## How this was made

- **Scope.** 70 files read in full: every record and README in `Newton-analysis/_dscn_mass_estimator/` (flat files, `ours26/`, `ours27/`, `ours29/`, `noise_vs_signal/` with `ours28b/`, `mass_estimator_equation/README.md`) and the two non-`-informing` files of `_note_mass_estimator_equation/`. `literature_review/` and `unsanctioned/` were left out: the discussion README keeps them out of its argument, and their code is VD-Newton's.
- **Pass 1, what was computed.** Ten readers listed every computed result (a number, table, simulation or check) with the record's own words on where it was computed. Ten independent critics re-read the same files for anything missed.
- **Pass 2, can it be rerun now.** For each result, twelve classifiers asked whether the code *and* the inputs still exist, and cited the file (tester commit and path, reference script, VD-Newton path). Twelve skeptics then attacked every verdict in both directions and changed 18. "Run in Claude's sandbox" alone does not make a result lost: the tester is seeded, so a sandbox run of a preset that is now committed can be regenerated exactly.
- **Checked mechanically.** Every quote below appears verbatim in the records. Every tester commit and file cited exists at that commit. Every reference script cited exists. Every `.tools/` path cited exists on this laptop.
- **Nothing was assumed.** A result is rerunnable only if a file can be pointed to. When a record does not say how a number was computed and nothing kept can be tied to it, it is listed as unknown.
