## The holes, stated before any result

1. **ν_eff's default.** The GUM's fallback for an unstated ν is infinity, the fixed-size Gaussian,
   which fails T30 (`test_t30_fails_for_the_fixed_size_gaussian`). So a bare σ is a real gap in the
   type, not a convention. **Unknown yet.**
2. **Positivity in the size posterior.** The posterior over $v_i$ uses the strong-signal count
   $Q\mid v\sim v\chi^2_{\nu}$, applied to $Q_+$; the sign condition's extra share (O13's ½) is not
   counted. Expected to matter for anti-parallel and near-boundary readings.
3. **Weak signal.** At weak signal the misfit carries information about the signal size as well as
   the noise size; the size posterior ignores it. ours27 (no η) under-covered badly at weak signal;
   whether the exact cut factor repairs that alone is the first study.
4. **The power form.** L21 was ruled as $E_i^{g}$; ours31 uses the exact cut factor, of which the
   power is the first order (T37 (4)). Which is the body is G19, a ruling.

**The break and the premise it names (hole 3, as predicted).** The size posterior reads a reading's
noise size from its misfit with the strong-signal count, $Q\mid v\sim v\chi^2_\nu$. At weak signal that
law is wrong: fitting the line soaks up noise, so $E[Q]$ falls below $\nu$ (in 3D at null it is
$\nu/2$, Codex's exact value, O14 27 Oct). The posterior then concludes each reading's noise is
*smaller* than stated, raises its precision above 1 (T37 (3)), and twenty over-trusted readings make
the law narrow. **The premise named:** the misfit's law given the noise size depends on the reading's
own signal size, which nothing declares (L10). In standard terms the misfit is not a pivot for the
noise size at weak signal: the signal size is a nuisance parameter of the cut likelihood, and T37's
count is that likelihood's strong-signal limit.

**What ours30 was doing there.** Its numerator $\kappa=\sup_\lambda E[Q_+]$ (O13) answers the same
question conservatively, by the largest misfit any size produces, and its cap stops the precision
rising above 1. Both were patches for the undeclared signal size, which is why they looked forced
"by meaning"; T37 and B12 say they are not the cut posterior of any stated noise.

**Open, not sorted:** how the cut should read the size when the signal size is undeclared. The
standard routes: condition on the reading's own signal statistic (its larger Gram eigenvalue; Codex's
decomposition $Q/v=q(A,W,V)$ in O14 has the joint law), which is per reading and borrows nothing
(L19); or bound over sizes, as O13 did; or integrate over sizes, which L10 forbids without a declared
size law. A sort, Claude's, next.
