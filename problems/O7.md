### 26–27 Oct: Z splits in two, and the split is an input (Claude; generation session of
26 Oct, sorted 27 Oct; not ruled)

**Can (26 Oct):** "we still don't know what should happen with the zeros; all the rulings
about them were always provisional."

- A zero-signal reading carries no mass information (no direction, no ratio), but its misfit
  is pure noise with the full $k$ degrees of freedom. The along-line channel goes blank
  exactly where the off-line channel is cleanest (O14, the second noise channel).
- So L20 bundles two claims. **Z for mass:** a reading with no mass information does not move
  the mass. **Z for noise:** it does not move the width. The second holds only if the noise is
  fully known.
- **Sorted as outcome 2, an input** (`../TASK.md` §3). Whether $\Sigma_i$ is declared exact or
  exact up to one overall scale is an instrument fact the readings cannot supply. That matches
  `TASK.md` §6's line on O7: what counts as "no information" is fixed by what the inputs
  declare.

| $\Sigma$ declared | what a zero reading does | Z | the misfit Q |
| --- | --- | --- | --- |
| exact | nothing to the law | holds in full | a check: $Q\gg\nu$ flags a bad declaration |
| up to a scale | nothing to the point; informs the width | holds for mass, narrowed for noise | an estimate: feeds the scale |

- The all-zero experiment survives both branches: no mass information anywhere, so the law
  is $\pi$ and its centre is $c$.
- ours29 already sits between the branches: $g=\min(1,\nu/Q)$ is a one-sided, per-reading
  scale learner (it widens, never narrows). The up-to-scale branch generalises it rather than
  contradicting it.
- **Guard (`TASK.md` §5):** this input is real. Instrument sheets do state noise with or
  without a calibrated scale. It is not being moved to the type because it is hard.

**Open, before this can close O7:**
1. The type has no slot for "up to scale". Add one to `../definition/type.md`, or show
   per-instrument classes (O14's one $\eta$ per noise pair) are the same fork repeated.
2. Does $\eta$ move the point or only the width? If the point, the scale branch could worsen
   O2's null-reading blocker. Readable from T8: $\eta$ multiplies the evidence, so it moves the
   law's shape and therefore the point; the STATE.md gap on the peak (ln m 1.1181 at
   $\eta=0.403$ against 1.2181 at $\eta=1$) is a case. So the scale branch must keep null
   readings out of the point some other way; that is the real constraint.
3. Zeros beside a signal (the item as asked) are not touched by this split; they are a
   question of what $k_i$ declares (T25).

### 27 Oct pressure result: a pooled scale does not preserve the existing point

Codex derived a finite counterexample in `O14.md` (27 Oct, section 4). Two 2D readings
have sum Q=4, sum nu=2; one exact-zero reading changes the pooled variance from 2 to
4/3. Using its reciprocal as an evidence power changes the cloud point even with the
original cloud-size function **frozen**. This is independent of O2's added-cloud failure.
The precision cap is inactive, and eta itself is unchanged. The law's median moves too.
`tests/test_pooled_reference.py` checks the explicit case and independent integrals.

O14 also proves that each separately profiled Q has a signal-dependent finite-SNR
distribution, with strong-signal mean (k-1)v, not that mean at every signal size. A
random zero-signal experiment, a fixed-mass residual, and an exactly zero observed
reading are different objects. The table above remains a **proposed requirement**, not
a property the pooled-and-powered construction has achieved. The input sort is not
ruled or refuted here; its point constraint remains unsolved.
