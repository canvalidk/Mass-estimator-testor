# outbox/VD-docs/: what this repo posts to VD-docs

VD-docs is a space for **made decisions** (his ruling, 2026-10-22). So only two
kinds of document go in here:

1. **A record whose subject is a decision**: a ruling of his, or the argument
   he accepted as settling an open item.
2. **A newly cut draft of one of the two VD-docs notes**: the next lemma list
   (`_note_mass_estimator_lemmas`) or the next statement of the equation
   (`_note_mass_estimator_equation`).

Work does not post: tests, studies, explorations, candidates, literature,
evidence or intermediate equation states stay in `docs/`. If you are unsure
whether something is a decision, it stays here.

Put the file here as it should be filed. Claude carries it to VD-docs,
files it there and empties this folder. The record of the transfer lives in
the VD-docs `inbox` ledger, so nothing needs writing here.
